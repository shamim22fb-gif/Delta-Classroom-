# SA Delta Classroom

A modern online classroom platform built with **Next.js 15**, **Supabase**, and **Tailwind CSS**.

## Tech Stack

- **Framework:** Next.js 15 (App Router, Server Components, Server Actions)
- **Database & Auth:** Supabase (PostgreSQL + RLS + Storage)
- **Styling:** Tailwind CSS
- **Validation:** Zod
- **Hosting:** Vercel
